# 超级资料

考公、考研一站式课程资料导航站，收录最新全网优质课程资源，持续更新。

## 网站介绍

超级资料（chaojiziliao.com）是一个专注于考公和考研的课程资料导航平台，整理了全网最新、最全的考试课程资源，方便考生快速找到需要的学习资料。

网站采用纯静态页面设计，加载速度快，手机、平板、电脑都能完美适配。

## 主要内容

### 考公课程目录
覆盖公务员、国考省考、教师招聘、事业单位、军队文职、三支一扶、社区工作者、英语、财会、司法考试等各类公职类考试课程。

### 考研课程目录
涵盖考研英语、数学、政治、管理类联考、各专业专业课、笔试冲刺、押题预测、复试辅导等全阶段考研课程。

### 免费笔记网盘群
共享学习笔记、思维导图、资料合集等免费学习资源。

### 课程更新日志
实时记录最新课程更新动态，方便跟踪学习进度。
